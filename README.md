Оксентьево Надкоторское

Исторический проект, посвящённый деревне Оксентьево Надкоторское (современное Пушкино, Лужский район Ленинградской области).

Первое упоминание

1498 год — писцовые книги Шелонской пятины Новгородской земли.

Цели проекта
Сохранение исторической памяти.
Исследование происхождения деревни.
Создание цифровой книги памяти жителей.
Сбор фотографий, документов и воспоминаний.
Историческая справка

Первым известным владельцем деревни был Сенка (Семён) Оксентьев — новгородский земец, упомянутый в писцовой книге 1498 года.

Его имя сохранилось в названии деревни на протяжении более пяти столетий.

Проект развивается

Планируется публикация:

исторической хроники;
архивных документов;
старых фотографий;
семейных историй;
карт и генеалогических материалов.
